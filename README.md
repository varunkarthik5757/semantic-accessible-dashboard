# semantic-accessiblr-dashboard

## Responsive Design & CSS Architecture

This project uses a mobile-first responsive CSS architecture with modern design tokens.

### Features

- CSS custom properties for design tokens
- Responsive CSS Grid and Flexbox layouts
- Responsive breakpoints for 320px, 768px, 1024px and 1440px
- Glassmorphism effects
- Soft shadows and hover transitions
- Dark and light theme variables
- Mobile horizontal overflow prevention

### Responsive Testing

The dashboard was tested at:

- 320px — Mobile
- 768px — Tablet
- 1024px — Laptop
- 1440px — Desktop

Responsive screenshots are available in the `screenshots/` directory.
